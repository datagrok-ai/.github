## What it does

Datagrok is an end-to-end platform for your data. Any data. Every team. All the tools.

* **Access.** Bring together data from different silos and formats.
* **Transform.** Clean, join, filter, aggregate, and pivot your datasets.
* **Explore.** Visualize, filter, and explore massive datasets in real time.
* **Compute.** Run scientific computations that are fast, scalable, and reproducible.

## Open source

Our plugins and database connectors are open source:

* **[public](https://github.com/datagrok-ai/public).** Plugins for cheminformatics,
  bioinformatics, and more.
* **[grok-connect](https://github.com/datagrok-ai/grok-connect).** Connectors to more than
  30 databases.

## For our team

New to the team? Two commands get you every repository you can access:

```bash
npm install -g datagrok-tools
grok src clone
```

For the prerequisites and what to do next, see the
